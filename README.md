# RECORD — iOS

The native iOS app for RECORD: share one song a day with friends.
A daily music diary — one song, one day, one note.

Built with SwiftUI + Supabase. Work in progress.

🌐 Web version: https://recordapp.live

## Stack
- SwiftUI (iPhone)
- Supabase (Postgres + Auth)
- iTunes Search API / Spotify Web API

## Status
Early development — auth working, building the core posting loop.
